======================================================================
1. VALIDAZIONE DELLE TRIPLE DELLO SPATIAL GRAPH
======================================================================

Il comando seguente genera le triple dello spatial graph, applica il
validatore automatico e crea il file XLSX per la revisione manuale.

cd ~/LG_project/arch-agent || exit 1

BASE="/mnt/c/Users/Utente/Desktop/Lucrezia/Lu_test_project/triple_validation_outputs"
TODAY=$(date +"%Y%m%d")

TEST_N=1
while [ -d "$BASE/scena4_L1_revalidation_${TODAY}_test_${TEST_N}" ]; do
  TEST_N=$((TEST_N + 1))
done

OUT="$BASE/scena4_L1_revalidation_${TODAY}_test_${TEST_N}"
mkdir -p "$OUT"

pixi run python validate_triples.py \
"/mnt/c/Users/Utente/Desktop/Lucrezia/Lu_test_project/laz_archdataset_segmented/scena4_VAL.laz" \
--graph spatial \
--annotation-csv "/mnt/c/Users/Utente/Desktop/Lucrezia/Lu_test_project/laz_archdataset_segmented/scena4_VAL_annotations.csv" \
--eps 0.5 \
--min-samples 15 \
--distance-threshold 2.0 \
--annotation-match-threshold 2.0 \
--sample-n 150000 \
--output-dir "$OUT"

cat "$OUT"/spatial_triples_report_*.txt
column -s, -t "$OUT"/spatial_triples_summary_by_relation_*.csv
find "$OUT" -name "spatial_triples_manual_review_*.xlsx"

File principali prodotti:

- spatial_triples_raw_*.csv/json
  Triple generate dal sistema, senza giudizio.

- spatial_triples_validation_*.csv/json
  Triple con valutazione automatica.

- spatial_triples_manual_review_*.xlsx
  File da compilare manualmente.

- spatial_triples_report_*.txt
  Conteggi complessivi e stato della validazione.

- spatial_triples_summary_by_relation_*.csv
  Numero di triple per relazione.

Predicati CIDOC principali:

- crm:P2_has_type: associa l'oggetto alla sua tipologia.
- crm:P45_consists_of: associa l'oggetto al materiale.
- crm:P103_was_intended_for: associa l'oggetto alla funzione.
- crm:P46i_forms_part_of: indica che una feature forma parte di un oggetto.
- crm:P56_bears_feature: indica che un oggetto porta una feature.

======================================================================
3. COMPILAZIONE DEL FILE MANUAL REVIEW
======================================================================

Nel file spatial_triples_manual_review_*.xlsx oppure
cidoc_triples_manual_review_*.xlsx compilare:

- manual_label: correct oppure incorrect
- manual_issue: tipo di errore rilevato
- manual_note: spiegazione della valutazione

Se si compilano soltanto le eccezioni, le celle manual_label lasciate vuote
possono essere interpretate come conferma del validatore usando l'opzione:

--blank-means-confirm

======================================================================
6. OUTPUT DEL CONFRONTO AUTOMATICO-MANUALE
======================================================================

La cartella manual_evaluation contiene:

- manual_evaluation_*.json
- manual_evaluation_*.csv
- manual_evaluation_*.xlsx
- manual_evaluation_*.txt
- manual_evaluation_*_confusion_matrix.png

Metriche calcolate:

- TP: validatore valid e revisione correct
- FP: validatore valid e revisione incorrect
- FN: validatore invalid e revisione correct
- TN: validatore invalid e revisione incorrect
- Precision
- Recall
- F1-score
- Accuracy
- Acceptance rate manuale

La matrice di confusione usa il formato:

[[TN, FP],
 [FN, TP]]

Nota: il numero di triple non coincide necessariamente con il numero di
archi NetworkX. Piu predicati fra la stessa coppia direzionale possono essere
memorizzati all'interno dello stesso arco del grafo.

In questo test vengono generate e validate soltanto le triple dello spatial
graph derivate dalla point cloud e dalle classi semantiche. I CSV vengono

Il batch:

- elabora tutte le scene LAZ;
- usa DBSCAN con eps=0.5 e min_samples=15;
- usa distance_threshold=2.0 m;
- carica al massimo 150000 punti per scena;
- genera raw, validation, manual review e report per ogni scena;
- continua sulle scene successive in caso di errore;
- genera un riepilogo complessivo CSV, JSON e TXT.
